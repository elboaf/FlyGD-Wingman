# Assets

Images referenced by the project README. Both files below are **not yet in the
repository**. The README references them from HTML comments, so it renders
without broken images until they are added — adding a file means dropping it
here and uncommenting the matching line near the top of `README.md`.

## `wingman-logo.png`

The FlyGD Wingman emblem.

- Square, transparent background, at least 512×512 (rendered at 128 px).
- Must be original or properly licensed artwork. Do **not** use Google,
  YouTube, OBS Studio, EVE Online, or Discord artwork — this project is not
  affiliated with any of them.

## `wingman-screenshot.png`

One screenshot of the main FlyGD Wingman window, used as the README hero image.

- Capture the main window with several recordings listed and at least one row
  showing a filled-in **YouTube Link**, so the core workflow is visible at a
  glance.
- Roughly 1350×650 (the window's default size); PNG.
- **Redact before committing**: the YouTube link column, filenames, and the
  window's own title bar can expose real video IDs and paths. Never capture the
  Settings dialog with a Discord webhook URL visible — a webhook URL is a
  bearer credential.
